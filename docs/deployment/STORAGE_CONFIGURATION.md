# MUXARO — Cloudflare R2 Storage Configuration Guide

## 1. Overview & Honest Storage Mode Selection

MUXARO uses [`apps/api/src/services/storage.service.ts`](../../apps/api/src/services/storage.service.ts) — a zero-dependency, pure-Node (`node:crypto` AWS Signature Version 4 `AWS4-HMAC-SHA256`) S3-compatible client designed for **Cloudflare R2** (zero egress fees).

- **Automatic safe mode selection:**
  - `storageMode: 'r2'` is active **only** when all 4 required environment variables (`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`) are present.
  - When any credential is unset (e.g., local development), MUXARO cleanly operates in `storageMode: 'local'` using isolated `.muxaro-uploads/` and `.muxaro-artifacts/` directories and reports `r2Configured: false` on `GET /api/v1/ready`.
  - MUXARO **never** claims R2 is connected when credentials are absent.

## 2. Bucket & Prefix Layout

Create a single private Cloudflare R2 bucket (e.g., `muxaro-media-prod`) with **Public Development URL disabled**.

All objects are stored under strict server-generated, path-traversal-proof logical prefixes:

| Prefix | Purpose | Recommended Retention |
| :--- | :--- | :--- |
| `uploads/` | Resumable user computer uploads pending FFmpeg processing | 24 hours (auto-purge) |
| `processed/` | Completed MP4/MKV/WebM/MP3/FLAC/WAV/M4A/Opus artifacts | 60 minutes (signed URL TTL) + 24h bucket lifecycle safety net |
| `playlists/` | Packaged multi-item ZIP archives | 60 minutes (signed URL TTL) + 24h bucket lifecycle safety net |
| `temporary/` | Intermediate scratch chunks & abandoned multipart artifacts | 24 hours (auto-purge) |

Key format generated by `storageService.generateObjectKey(prefix, ownerId, filename)`:
```text
<prefix>/<YYYYMMDD>/<sha256(ownerId)[0..12]>/<24-hex-nonce>_<sanitizedFilename>
```
- Owner IDs are hashed (never raw emails or user IDs in object keys).
- Path traversal (`..`), null bytes, backslashes, leading slashes, and unapproved prefixes are strictly rejected by `assertSafeObjectKey()`.

## 3. Environment Variables

Configure these in **Google Cloud Secret Manager** (mounted into Cloud Run API & Worker services) — never commit them to Git:

| Variable | Required for R2 | Example / Notes |
| :--- | :---: | :--- |
| `R2_ACCOUNT_ID` | Yes | 32-char Cloudflare Account ID |
| `R2_ACCESS_KEY_ID` | Yes | R2 API Token Access Key ID (scoped strictly to `muxaro-media-prod`, Object Read & Write only) |
| `R2_SECRET_ACCESS_KEY` | Yes | R2 API Token Secret Access Key |
| `R2_BUCKET_NAME` | Yes | `muxaro-media-prod` |
| `R2_REGION` | No | Defaults to `auto` |
| `R2_ENDPOINT` | No | Defaults to `https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com` |
| `R2_PUBLIC_ENDPOINT` | No | Optional custom domain if binding R2 behind Cloudflare CDN |

## 4. Bucket CORS Policy (Cloudflare Dashboard -> R2 -> Settings -> CORS)

Only required if enabling direct browser-to-R2 multipart PUTs; for API-proxied uploads/downloads, CORS can remain empty. When enabling direct uploads:

```json
[
  {
    "AllowedOrigins": [
      "https://muxaro.app"
    ],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["Content-Type", "Content-Length", "Range", "If-Range", "x-amz-meta-sha256"],
    "ExposeHeaders": ["ETag", "Content-Range", "Content-Length", "Accept-Ranges"],
    "MaxAgeSeconds": 3600
  }
]
```

## 5. Lifecycle Auto-Purge Rules (Cost & Privacy Protection)

Configure **Object Lifecycle Rules** on the R2 bucket in Cloudflare Dashboard -> R2 -> `muxaro-media-prod` -> Settings -> Object lifecycle rules:

1. **Delete `uploads/` after 1 day** (`Prefix: uploads/`, Action: Delete objects after `1` day).
2. **Delete `processed/` after 1 day** (`Prefix: processed/`, Action: Delete objects after `1` day).
3. **Delete `playlists/` after 1 day** (`Prefix: playlists/`, Action: Delete objects after `1` day).
4. **Delete `temporary/` after 1 day** (`Prefix: temporary/`, Action: Delete objects after `1` day).
5. **Abort incomplete multipart uploads after 1 day** (`Prefix: ""`, Action: Abort incomplete multipart uploads after `1` day) — guarantees abandoned browser uploads never accrue hidden R2 storage costs.

Additionally, `storageService.deleteExpiredObjects(prefix, maxAgeMs)` provides programmatic sweep support for scheduled cleanup jobs.

## 6. Signed Download Delivery (AWS SigV4 Presigned URLs)

`storageService.getPresignedDownloadUrl(key, { expiresInSeconds, filename, inline })` generates time-limited (`60s`–`86400s`, default `3600s`) `AWS4-HMAC-SHA256` presigned GET URLs with:
- Exact `response-content-disposition` (`attachment; filename="..."` for direct saves, or `inline; filename="..."` for `<video>`/`<audio>` preview).
- Native Cloudflare R2 HTTP `Range` (`206 Partial Content`), `ETag`, `Last-Modified`, `If-Range`, and `416` resume support with zero egress fees.
- SHA-256 integrity tagging via `x-amz-meta-sha256` on every `putObject()` call.
