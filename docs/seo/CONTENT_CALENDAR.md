## 3. Production Workflow & Quality Checklist

Every article on the calendar must pass the **Five-Point Hallmark Gate** prior to deployment:
1. [ ] **Fact Check:** Every claim grounded in MPEG, IETF, or SMPTE standards.
2. [ ] **FFmpeg Verification:** Accompanying terminal command tested and verified on macOS, Linux, and Windows.
3. [ ] **Schema Check:** Validated JSON-LD (`TechArticle` or `HowTo`) embedded in static HTML.
4. [ ] **Bidirectional Link:** Contextual link to relevant `/tools/*` page and return link from tool to doc.
5. [ ] **No AI Slop:** Zero clichés, zero fake stats, zero padding.
