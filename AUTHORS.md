## Open-Source Ecosystem & Runtime Assets

MUXARO builds on proven open-source foundations:

- **Web Stack:** Next.js 16, React 18, TypeScript 5, Tailwind CSS 3, PostCSS 8, Lucide Icons (`lucide-react`)
- **Client Media & Stream Tooling:** `@ffmpeg/ffmpeg`, `@ffmpeg/util`, `@ffmpeg/core` (browser WebAssembly worker runtime), `@distube/ytdl-core`
- **Typography:** Inter & JetBrains Mono (`OFL-1.1` via `next/font/google`)
